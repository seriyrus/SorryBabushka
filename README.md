# ☕ Coffee Shop Landing Page

Современный, адаптивный и эстетичный лендинг для кофейни, созданный с использованием семантического HTML5 и современного CSS3. Проект вдохновлен дизайном [Cafe Demo Template](https://websitedemos.net/cafe-04/), но полностью кастомизирован под уникальную цветовую палитру и собственные медиа-материалы.

Демо - https://seriyrus.github.io/SorryBabushka/

## 🚀 Особенности проекта

- 📱 **Полная адаптивность**: Mobile-first подход, корректное отображение на всех устройствах (смартфоны, планшеты, десктопы).
- 🎨 **CSS-переменные**: Гибкая система управления цветами и типографикой.
- ✨ **Плавные анимации**: Fade-in при скролле (Intersection Observer), hover-эффекты, параллакс для фоновых изображений.
- ⚡ **Оптимизация производительности**: Использование формата изображений `.webp`, lazy loading для галереи.
- ♿ **Доступность (a11y)**: Семантическая верстка, ARIA-атрибуты, достаточный контраст цветов (WCAG).
- 🧩 **Модульная структура**: Чистый, комментированный код, удобный для поддержки и масштабирования.

## 🎨 Цветовая палитра

Проект использует тщательно подобранную палитру (значения вынесены в CSS-переменные):

| Название | Hex-код | Применение |
| :--- | :--- | :--- |
| **White Diamond** | `#F5F5F0` | Основной фон, текст на темном фоне |
| **Rainforest Foliage** | `#1B5E4A` | Заголовки, основной текст, футер, хедер |
| **Peony** | `#D44375` | Акцентные элементы, hover-эффекты, цены |
| **Fireball Orange** | `#E06B3A` | CTA-кнопки (призыв к действию), важные бейджи |
| **Jet Stream** | `#B8D4E3` | Вторичные фоны, подзаголовки |
| **Wasabi** | `#C4B76A` | Иконки, рейтинг (звезды), декоративные элементы |

## 🛠 Технологический стек

- **HTML5** (семантическая разметка)
- **CSS3** (Flexbox, CSS Grid, Custom Properties, Media Queries)
- **Vanilla JavaScript** (минимальный скрипт для мобильного меню, плавного скролла и анимаций при прокрутке)
- **Google Fonts** (Poppins / Montserrat)
- **Font Awesome** (или SVG-иконки)
